# EEG Montage

ACNS describes standard clinical EEG montage approaches, including bipolar and referential arrangements.

For an image-analysis agent, montage identification is an observation task.

Possible visible categories may include:
- longitudinal bipolar
- transverse bipolar
- referential

If the montage is not clearly identifiable, state that it is unavailable or uncertain.

Localization and phase-reversal reasoning must not be applied as though the montage were known when it is not.

Source:
ACNS Guideline 3, A Proposal for Standard Montages to be Used in Clinical EEG.
