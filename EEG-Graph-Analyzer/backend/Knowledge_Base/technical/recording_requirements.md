# EEG Recording Technical Requirements — Evidence Note

## Purpose

Technical quality affects how confidently EEG findings can be interpreted.

ACNS Guideline 1 provides minimum technical requirements for clinical EEG. The project should use the guideline as the primary source for acquisition standards rather than hard-coding copied values from a PDF extraction.

## Image-agent rule

The agent should report technical details only when visible.

Potentially relevant technical fields:
- electrodes/channels
- electrode nomenclature
- montage
- reference
- sensitivity/amplitude calibration
- time scale
- filters
- sampling information
- recording duration
- patient state
- display quality

## Screenshot limitation

A screenshot can omit acquisition metadata and continuous context. Missing information must remain missing.

Source:
ACNS Guideline 1, Minimum Technical Requirements for Performing Clinical EEG.
