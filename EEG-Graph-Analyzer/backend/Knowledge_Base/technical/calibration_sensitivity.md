# Calibration and Sensitivity

Amplitude interpretation depends on the displayed calibration/sensitivity.

Rules:
- If calibration is visible, report the displayed value exactly as read.
- If calibration is absent or ambiguous, do not invent microvolt values.
- Do not convert visual height into amplitude without a reliable scale.
- Treat OCR of calibration text as uncertain unless visually confirmed.

Source:
ACNS technical guidance for clinical EEG recording and display.
