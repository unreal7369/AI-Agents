# Time Scale and Frequency

Frequency estimation requires a reliable time scale.

Rules:
- If a time bar or scale is clearly visible, it may support an approximate frequency estimate.
- If no reliable time calibration is visible, use qualitative terms such as "slow," "rhythmic," or "fast" only when supported.
- Do not report exact Hz from waveform appearance alone.
- A single static image cannot establish temporal evolution outside the displayed interval.

Source:
ACNS standardized terminology and clinical EEG technical guidance.
