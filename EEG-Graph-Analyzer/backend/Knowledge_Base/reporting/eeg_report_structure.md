# EEG Report Structure

Use a structured report:

1. Study/input description
2. Technical information visible in the image
3. Background
4. Focal or generalized abnormalities
5. Rhythmic/periodic/epileptiform features, if supported
6. Artifacts/limitations
7. Impression
8. Clinical-context and full-recording limitation

The report should separate objective description from interpretation.

Source:
ACNS Guideline 7, Guidelines for EEG Reporting.
