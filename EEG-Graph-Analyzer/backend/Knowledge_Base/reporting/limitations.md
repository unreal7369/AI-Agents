# Image-Based EEG Limitations

An image cannot reliably provide all information available in the original EEG.

Potentially missing:
- continuous temporal context
- complete channel set
- raw signal
- montage/reference
- calibration
- filters
- sampling rate
- clinical history
- patient state
- video/behavioral correlation

Therefore the report should not imply that the screenshot is equivalent to interpretation of the complete EEG.
