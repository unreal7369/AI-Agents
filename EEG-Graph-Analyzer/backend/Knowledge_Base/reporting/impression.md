# EEG Impression

The impression should be concise and evidence-constrained.

Preferred structure:

- Main visible EEG abnormality, if supported.
- Degree of confidence.
- Important artifact/mimic limitation.
- Need for complete EEG/clinical correlation when appropriate.

Example:
"Abnormal-appearing displayed EEG segment with prominent slowing and sharp-contoured transients. The supplied screenshot is insufficient to determine whether the sharp activity is definitively epileptiform or ictal. Correlation with the complete multichannel recording is recommended."

This is an example of wording, not a diagnostic rule.
