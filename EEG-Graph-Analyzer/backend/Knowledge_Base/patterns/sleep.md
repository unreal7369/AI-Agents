# Sleep EEG Patterns

Normal sleep can produce characteristic EEG changes, including:
- drowsiness-related changes
- vertex waves
- sleep spindles
- K-complexes
- NREM background changes
- REM-associated features

The image agent should not infer sleep stage unless the visible waveform and context support it.

A sleep-related transient should not automatically be called epileptiform.

Source:
American Epilepsy Society EEG atlas, NCBI Bookshelf, 2016.
