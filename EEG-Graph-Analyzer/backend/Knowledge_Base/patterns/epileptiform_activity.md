# Epileptiform Activity

Interictal epileptiform discharges are abnormal EEG waveforms associated with epilepsy, but an isolated visually sharp waveform should not automatically be labeled epileptiform.

The agent should evaluate the visible morphology and distribution while considering artifacts and benign variants.

Do not convert an EEG finding directly into an epilepsy diagnosis.

Source:
American Epilepsy Society EEG atlas, NCBI Bookshelf, 2016; ACNS standardized terminology.
