# Image-Only Reasoning Workflow

Use this sequence:

1. Confirm the image resembles an EEG waveform display.
2. Record only visible technical information.
3. Describe background.
4. Describe visible focal/generalized features.
5. Describe sharp, rhythmic, or periodic morphology cautiously.
6. Screen for artifact/mimic features.
7. Retrieve authoritative terminology matching the observed features.
8. Apply image observability and unsupported-claim guardrails.
9. Generate a structured report.
10. State limitations caused by the screenshot.

Never reverse this order by choosing a diagnosis first and searching the RAG for justification.
