# No Unsupported Diagnosis

The agent must separate:

1. visible waveform features
2. compatible EEG terminology
3. possible clinical significance
4. information that cannot be concluded

Do not convert:
- sharp-looking activity -> seizure
- rhythmic activity -> seizure
- periodic activity -> seizure
- focal abnormality -> epilepsy
- epileptiform discharge -> epilepsy diagnosis
- a classifier label -> patient diagnosis

A single image may support a descriptive impression but usually cannot establish the full clinical diagnosis.
