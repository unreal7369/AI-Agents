# ACNS Pattern Modifiers

ACNS terminology uses modifiers to describe EEG patterns more precisely.

Depending on the visible recording, relevant descriptors can include:
- prevalence
- duration
- frequency
- amplitude
- morphology
- spatial distribution
- laterality
- evolution
- plus modifiers

Only report a modifier when the supplied image contains enough information to support it.

Do not invent an exact value when the display scale is unavailable.

Source:
Hirsch LJ et al., ACNS Standardized Critical Care EEG Terminology: 2021 Version.
