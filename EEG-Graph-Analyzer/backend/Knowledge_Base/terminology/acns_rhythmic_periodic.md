# ACNS Rhythmic and Periodic Pattern Terminology

ACNS 2021 distinguishes rhythmic and periodic patterns using waveform organization and inter-discharge relationships.

Relevant categories include:
- lateralized periodic discharges (LPDs)
- generalized periodic discharges (GPDs)
- lateralized rhythmic delta activity (LRDA)
- generalized rhythmic delta activity (GRDA)

The agent should not assign one of these labels from a vague visual resemblance. Pattern classification requires adequate morphology, spatial distribution, recurrence, and frequency information.

Source:
Hirsch LJ et al., ACNS Standardized Critical Care EEG Terminology: 2021 Version.
