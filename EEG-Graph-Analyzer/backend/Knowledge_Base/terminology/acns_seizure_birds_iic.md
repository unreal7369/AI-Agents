# ACNS Seizures, BIRDs, and IIC

The ACNS 2021 terminology includes:
- electrographic seizures
- electroclinical seizures
- brief potentially ictal rhythmic discharges (BIRDs)
- ictal-interictal continuum (IIC)

These are specialized terms with specific criteria.

The image agent must not treat any one visual feature as sufficient by itself.

A static screenshot is especially limited for seizure/evolution assessment.

Source:
Hirsch LJ et al., ACNS Standardized Critical Care EEG Terminology: 2021 Version.
