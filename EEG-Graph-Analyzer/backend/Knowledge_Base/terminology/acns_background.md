# ACNS Background Terminology

Background description should consider the observable organization and relevant modifiers rather than assigning a disease diagnosis.

Potential descriptors include:
- dominant frequency
- amplitude
- continuity
- symmetry
- variability
- reactivity, when demonstrated
- state changes, when demonstrated

The image agent should report only properties supported by the displayed segment.

Source:
Hirsch LJ et al. ACNS Standardized Critical Care EEG Terminology: 2021 Version.
Scope note: primarily developed for critically ill patients; applicable outside critical care with appropriate caution.
