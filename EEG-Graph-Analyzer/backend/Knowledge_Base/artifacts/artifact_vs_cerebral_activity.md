# Artifact Versus Cerebral Activity

Before labeling a suspicious waveform as cerebral abnormality, consider:
- whether it has a plausible physiological or technical source
- whether it is restricted to particular channels
- whether it is synchronous with an expected artifact source
- whether its morphology is consistent across channels
- whether the displayed context is sufficient

If evidence is inadequate, report:
"Artifact cannot be excluded from the supplied image."

Do not silently delete suspicious waveforms from the analysis.
